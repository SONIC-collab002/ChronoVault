# **App Name**: ChronoVault

## Core Features:

- User Authentication: Implement user registration and login functionality.
- Capsule Creation: Enable users to create time capsules with text content and future delivery dates.
- Capsule Viewing: Allow users to view their created capsules with scheduled or delivered statuses.
- Automated Delivery: Automatically deliver the time capsules on their scheduled dates.

## Style Guidelines:

- Primary color: Deep violet (#673AB7), reminiscent of twilight, symbolic of memory and future dreams.
- Background color: Very light violet (#F3E5F5), subtle, blends into the background.
- Accent color: Blue-violet (#3F51B5), positioned to the 'left' of deep violet on the color wheel, giving contrast to key interactive elements.
- Body and headline font: 'Inter' sans-serif, lending the interface a modern, machined look suitable for the topic.
